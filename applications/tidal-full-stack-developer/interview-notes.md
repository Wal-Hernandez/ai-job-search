# Interview Notes: Tidal — ARG Full-Stack Developer

## STAR Stories

### Backend API migration (La Nación)
- **Situation:** The company relied on a legacy .NET 2.2 newsletter system that was hard to maintain and scale.
- **Task:** Migrate the system to Node.js + AWS and design the new REST APIs, data models and serverless workflows.
- **Action:** Designed the API contract and data model, implemented the Node.js backend, set up serverless workflows on AWS, and coordinated with Architecture, Database and Frontend teams.
- **Result:** Replaced the legacy pipeline with a maintainable, cloud-based backend. Later promoted to core developer on the Paywall monorepo.

### OpenAI document-processing integration (Eppical)
- **Situation:** A client needed documents analyzed automatically as part of an existing workflow.
- **Task:** Build the backend integration that routes documents to OpenAI APIs and returns the analysis results to Angular frontends.
- **Action:** Developed Node.js/.NET services to handle routing and result processing, built the Angular UI components, and collaborated with the team on technical trade-offs.
- **Result:** A working AI-assisted document-analysis pipeline integrated into the product.

### Production bug fix and feature delivery (SYNAgro)
- **Situation:** Customer-facing applications in the agribusiness sector had production issues and needed new features.
- **Task:** Fix bugs and implement new functionality across React, Ionic and .NET backends.
- **Action:** Built responsive web and mobile interfaces, wrote backend services and database changes, and resolved production bugs.
- **Result:** Improved application stability and delivered customer-facing features such as email layouts.
